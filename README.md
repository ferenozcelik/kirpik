# Kirpik

A lightweight, local screenshot tool for macOS. Native on Apple Silicon.

- Press **⌘⇧9** (configurable in Settings), drag to select an area on any screen
- Resize the selection from its corners and edges, move it with the select tool
- Magnifier with pixel position and color while selecting
- Annotate: pen, line, arrow, rectangle, filled rectangle, ellipse, marker, text, pixelate, numbered steps
- Hover a toolbar button for a short description
- Copy to clipboard or save as PNG
- **Copy text (OCR)** from the selection, on-device with Apple's Vision framework
- **Copy color** as a hex code with the eyedropper

## Install

Double-click `Install.command`, or:

```bash
./build.sh --install
```

Requires macOS 14 or later and Xcode or the Command Line Tools.

On the first capture macOS asks for **Screen Recording** permission:
System Settings → Privacy & Security → Screen & System Audio Recording → turn on Kirpik, then reopen it.

> Kirpik is ad-hoc signed, so the permission has to be granted again after every rebuild.

## Shortcuts while capturing

| Key | Action |
| --- | --- |
| ⌘C or ↩ | Copy and close |
| ⌘S | Save as… |
| ⌘Z / ⇧⌘Z | Undo / redo |
| Scroll | Change line and text size |
| ⇧ while drawing | Straight 45° lines, squares, circles |
| esc | Close (or leave the eyedropper) |
